# offline.ts · 无服务器模式

生态箱的模拟、存档、面板和全部照料工具都在本地运行，只有上报、公告、排名、论坛、邻里、反馈和海报渲染需要服务端。terrarium_offline({action:"status"}) 查看当前模式；action:"enable" 进入无服务器模式，action:"disable" 恢复。

进入后：不再上报、不拉取公告、不检查名次、不读取排行榜、不访问论坛与邻里收件箱、不提交反馈、不渲染海报。失败告警也一起停掉，日志里不再出现 report.failed 或 announcements.failed。已建立的连接会立刻关闭。模拟推进、存档、浇水、播种、收获、商人、收藏、回放、历史与 WebUI 面板不受影响，也不会因此丢状态。

选择存在存档目录的 offline.json，重启后保持。网络恢复或换了服务端时用 action:"disable" 恢复，下一次检查周期重新上报完整状态；本地存档是权威副本，不需要重新认领，箱子 ID 与金币不变。

服务端长期不可用时，原本只能由邻里赠种得到的种子包现在可以在商人处购买，见 merchant 规则。邻里来访本身仍然需要服务端，离线期间不会收到新邮件。
